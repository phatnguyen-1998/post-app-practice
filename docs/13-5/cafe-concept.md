# カフェのモバイルオーダーアプリ

## エンティティ一覧

| エンティティ | 何を覚えておくものか 　　　　　　　　　     | 主な属性                           |
| :----------- | :------------------------------------------ | :--------------------------------- |
| 商品         | その日に出るドリンクと料理                  | 名前、区分、値段、売れきるかどうか |
| 注文詳細     | 1件の注文に対して１つの商品、個数10以下　　 | 注文した商品名、合計金額、注文番号 |
| 注文         | お客様が一回で注文登録                      | 注文番号 、注文した時の日時        |

‐　会員登録機能がないのため。毎回注文した時何も残らない
‐　スタッフ用のアカウント登録もないから、店内のタッブレトで共有アカウントを使用します

## 関係の一覧

| エンティティA | 関係  | エンティティB | 読み方                                        |
| :------------ | :---- | :------------ | :-------------------------------------------- |
| 注文 　　　　 | 1対多 | 注文明細 　　 | 1件の注文は、1つ以上の注文明細を持つ          |
| 商品 　　　　 | 1対多 | 注文明細 　　 | 1つの商品は、複数の注文明細に現れることがある |
