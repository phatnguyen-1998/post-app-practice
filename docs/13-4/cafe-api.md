#　API-02 注文登録　の詳細
**メソッドとエンドポイント**: POST /api/oders

- **認証**: 不要
- **送るもの**: 本文で、注文する商品名と個数（個数は10個以下）
- **返すもの（うまくいったとき）**: 201。注文番号と合計、支払方法へ
- **返すもの（うまくいかなかったとき）**: 422（送ったものに不備があるとき、または選んだ商品が売り切れているとき）

# API-06: 注文を受け渡し済みにする

**メソッドとエンドポイント**: PUT /API/orders/{注文番号}

- **認証**: 必要
- **送るもの**: URLに注文番号、本文で、渡し済みにする
- **返すもの（うまくいったとき）**: 200。渡し済みにした後注文1件（注文番号、商品名、個数、合計金額、渡し済み）
- **返すもの（うまくいかなかったとき）**: 401（ログインしていないとき）、404（注文見つからないとき）
