#　投稿を書き換えるエンドポイントの詳細
**メソッドとエンドポイント**: PUT /api/posts/{post}

- **認証**: 必要
- **送るもの**: URLに投稿の番号。本文で、タイトル（必須・255文字以内）と、本文（必須）と、カテゴリの番号（必須・登録済みのカテゴリ）
- **返すもの（うまくいったとき）**: 200。書き換えたあとの投稿1件（投稿の番号・タイトル・本文・カテゴリの番号・投稿者の番号・登録日時・更新日時）
- **返すもの（うまくいかなかったとき）**: 401（ログインしていないとき）／403（自分の投稿ではないとき）／404（その投稿が見つからないとき）／422（送ったものに不備があるとき）

# エラーレスポンス一覧

｜起きること｜ステータスコード｜返すもの
｜ログインしていない｜401｜ログインが必要である旨の文言
｜自分の投稿ではない｜403｜権限がない旨の文言
｜投稿が見つからない｜404｜見つからない旨の文言
｜送ったものに不備がある（編集）｜422｜不備があった項目とその理由の文言
